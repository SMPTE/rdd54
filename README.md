## Details

This revision of SMPTE RDD 54, the mapping of ARRIRAW image essence into the MXF Constrained Generic Container, updates the 2022 edition for ARRI cameras and software released since. It adds an essence coding label for 12-bit reverse-packed ARRIRAW under High Density Encoding, three new SubDescriptor items that describe per-camera calibration data, black level and maximum sample value, and a color filter array label for monochrome sensors, and it clarifies several passages of the published text. A redline against RDD 54:2022 accompanies the draft. Implementers of ARRIRAW readers and writers are encouraged to review it and comment through the issue tracker of this repository.
